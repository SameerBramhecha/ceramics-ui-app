# Quickstart

## Prerequisites

- Node.js and npm installed
- Git repository cloned locally

## Setup

```bash
npm install
```

## Local development

```bash
npm run dev
```

Expected result: the Vite app runs in development mode and can be previewed locally.

## Production validation

```bash
npm run build
```

Expected result: the app bundles successfully for deployment.

## Quality validation

```bash
npm run lint
```

Expected result: lint checks execute without blocking issues under the repository’s configuration.

## Evidence of readiness

The feature is considered ready when the repository can be installed, started, built, and linted from a clean local clone without requiring manual project repair.
